- `src/model.ts` / `pnpm-workspace.yaml` 不在 stash 快照里（一直是工作区未跟踪文件，pop 时原地保留），先备份到 /tmp 并核对内容一致。

- 状态：仍在 `main`，改动全部在**暂存区**、未提交；`stash@{0}`（最新 Pi 版本）与 `stash@{1}`（更早备份）均保留未 drop。`feat/pi-agent-session` 仍指向 `786c9cc`。
- 教训：stash 应优先在它的 base 提交上 pop；跨基线 pop 会引入静默旧值回退，核对不能只看 `git diff --diff-filter=U`，要比对整个目标文件树。
